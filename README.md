🎓 Student Management System

A professional and responsive Student Management System built using HTML, CSS, and JavaScript. This project helps manage student records through a clean dashboard and stores data in the browser using Local Storage.

📌 About the Project

The Student Management System is a frontend web application designed to simplify basic student record management. Users can add, view, edit, delete, search, and filter student records.

✨ Features

- 📊 Professional dashboard with student statistics
- ➕ Add new student records
- ✏️ Edit existing student details
- 🗑️ Delete student records with confirmation
- 🔍 Search students by name, roll number, email, phone, or course
- 🎯 Filter student records by course
- 📱 Responsive layout for desktop and mobile
- 💾 Save student records using Browser Local Storage
- 📧 Email format validation
- 📞 Indian mobile number format validation
- 🚫 Duplicate roll number prevention

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Visual Studio Code
- Git and GitHub

🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in your browser.

Alternatively, install the Live Server extension in VS Code, right-click "index.html", and select Open with Live Server.

💾 Data Storage

Student records are stored in the browser's Local Storage. The data remains available after refreshing the page in the same browser, provided the site's stored data is not cleared.

Note: This project does not use a backend database. Data is not automatically synchronized between different browsers or devices.

✅ Validation

- Email addresses are checked for a valid format.
- Indian mobile numbers must contain 10 digits and start with 6, 7, 8, or 9.
- Duplicate roll numbers are not allowed.

These checks validate input formats; they do not verify that an email inbox or phone number is active.

🎯 Project Objective

The objective of this project is to practice frontend web development, JavaScript DOM manipulation, form validation, CRUD operations, and browser-based data storage.
